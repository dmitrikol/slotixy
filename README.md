# 🚀 Что умеет Slotixy

Полностью автоматизирует запись клиентов для сферы услуг.

Подходит для:

- 💅 Маникюр
- 💇 Парикмахерские
- 💈 Барбершопы
- 💆 Массаж
- 🏥 Косметология
- 🐕 Груминг
- 🦷 Стоматология
- 🏋️ Персональные тренеры
- 📚 Репетиторы
