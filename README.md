# 🚀 О проекте

**Slotixy** — современная система онлайн-записи клиентов через Telegram.

Проект разработан для автоматизации бизнеса, работающего по предварительной записи. Бот берет на себя рутинные задачи администратора: запись клиентов, управление расписанием, отправку уведомлений и ведение статистики.

- 📅 Просмотр записей на сегодня
- 📋 Все активные записи
- ➕ Добавление услуг
- ❌ Удаление услуг
- 🕒 Настройка рабочего графика

- 📊 Статистика
